# 赛题：AXI4 虚拟 FIFO — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **AXI4 虚拟 FIFO**（`axivfifo_public`，基于开源
alexforencich/verilog-axi 的 `axi_vfifo`，MIT 许可）：S 流（AXI-Stream）
数据经编码器切块后按段交替写入两个通道的**地址窗口环形缓冲**（每通道
独立 64 KB 确定性内存应答器闭合 AW/W/B 与 AR/R，写指针按 16 字突发边界
滚动即环），读引擎按同一窗口读回并重组为 M 流出队。你的任务是**设计并
生成测试激励（stimulus）**，使被测设计（DUT）的**功能覆盖率**最大化。

DUT 在标准虚拟 FIFO 之上带有若干需要**主动探测**的深水区特性：
隐藏的"正确写突发长度集合"（LEN_OK_SET，通道 0 写突发完全入队时按 awlen
判定；公开占位全 0、槽值 0 永不匹配 → 机制完全惰性）、正确完成后隐藏的
hold 驻留窗口（DONE_HOLD_N 拍，结束拍给出 done_ok 类脉冲）、以及窗口环
满/空背压、写满-读空、连续多写突发、长突发（awlen≥8）、len=0 快速完成、
窗口水位四档（0/1/16/32/64 字）等时序特性。功能的完整定义见
`dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的
  激励序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数
  （116 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [addr_d0, addr_d1, ch_sel, aw_ar, valid_pulse, last,
  wd_d0, wd_d1, wstrb_ctrl, aw_ready, ar_ready, cfg_wr, cfg_sel, cfg_d0,
  cfg_d1]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速
  迭代；评测阶段以真实 DUT 仿真结果为准。
- 116 个 bin 中 100 个在公开占位参数下可达；16 个依赖隐藏参数（评测端
  注入真值后可达，`verify_all_bins.py` 已实测）。要求尽可能多的 bin 被
  命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
python3 harness.py                      # random 曲线（backend=local）
python3 verify_all_bins.py              # 注入真值：ALL 116 BINS REACHABLE
python3 verify_all_bins.py --placeholder  # 占位对照：16 个惰性 bin

# 2) 周期级对拍（WSL + Verilator，包根目录）
python3 cross_check.py                  # 30000 拍 0 失配 -> CROSS CHECK PASS

# 3) 评测后端冒烟（harness 双后端）
python3 - <<'EOF'
from harness import AxivfifoHarness
import numpy as np
for backend in ("local", "verilator"):
    h = AxivfifoHarness(backend=backend)
    s = h.reset()
    rng = np.random.RandomState(3)
    for _ in range(500):
        s, r, d, i = h.step(rng.uniform(0, 256, 15).astype(np.float32))
    print(backend, "coverage=%.1f%%" % (h.coverage * 100))
EOF
```

## 5. 主要文件

| 文件 | 说明 |
|---|---|
| `dut/dut_spec.md` | 规格书：概述、隐藏机制、接口、拍级实测时序、动作空间、覆盖点与惰性清单、可见性分界 |
| `dut/coverage_meta.json` | 覆盖元数据（116 bins；total_bins == bins 之和） |
| `dut/covergroup.svh` | SystemVerilog covergroup（与 meta 逐 bin 同名同值） |
| `dut/assert_cov.svh` | SVA cover property（Q1..Q12 总线级等价 + deep + dataflow/timing，directive 名与 meta 一致） |
| `local_sim.py` | 周期精确 Python 模型（黑盒接口；cross_check 与 RTL 0 失配） |
| `coverage_simulator.py` | 覆盖率统计（generic bins + deep/sva tracker） |
| `harness.py` | 15 维动作解码 + 评测循环（双后端 default/load_secrets） |
| `inference_interface.py` | random / greedy 两条基线策略 |
| `cross_check.py` | local_sim vs Verilator 30000 拍对拍（CROSS CHECK PASS） |
| `verify_all_bins.py` | 注入真值后全部 116 bin 构造命中；--placeholder 惰性对照 |
