# 赛题：1G 以太网 MAC 控制器 — 激励生成任务（最高难档）

## 1. 赛题背景

给定一个**千兆以太网 MAC 控制器**（`ethmac_public`，基于开源
alexforencich/verilog-ethernet 的经典 `eth_mac_1g`（`eth_mac_1g_rx` +
`eth_mac_1g_tx`，lfsr CRC），MIT，顶层两侧各配一个 `axis_async_frame_fifo`
异步帧 FIFO），你的任务是**设计并生成测试激励（stimulus）**，使被测设计
（DUT）的**功能覆盖率**最大化。

DUT 在标准 1G MAC 收发之上带有若干需要**主动探测**的深水区特性：隐藏的
"正确帧长子集"（只有特定长度的 TX 帧完成才会触发 `frame_ok` 上报，类别
映射黑盒）、正确帧完成后的驻留窗口（长度隐藏）、异步帧 FIFO 的帧原子交付
时序（帧在 tlast 拍整体提交后才对 MAC 核心可见，TX 帧数据可被完整缓存）、
以及 RX 侧的错误帧 / 坏 FCS / 全双工并发等协议边界。功能的完整定义见
`dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的
  激励序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数
  （111 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [tx_byte_d0, tx_send, tx_tready, gmii_rxd_d0, gmii_rx_dv,
  gmii_rx_er, cfg_wr, cfg_sel, cfg_d0, cfg_d1, pad0..pad4]`
  （见规格书 §4；tx_send 为电平语义：=1 的每一拍注入一字节）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 全部 111 bin 均可达（已通过 `verify_all_bins.py` 在注入隐藏真值
  `len_ok_set=[1,3,254,255]`、`frame_hold_n=16` 下实测验证）。要求尽可能
  多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, ".")
import numpy as np
from harness import EthmacHarness

h = EthmacHarness(backend="local")     # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [tx_byte_d0, tx_send, tx_tready, gmii_rxd_d0, gmii_rx_dv,
#              gmii_rx_er, cfg_wr, cfg_sel, cfg_d0, cfg_d1, pad0..pad4]
# 例如：注入 2 字节 TX 帧（连续 2 拍 tx_send=1），随后等待完成。
for i in range(2):
    a = np.zeros(15, dtype=np.float32); a[0] = 0x5A; a[1] = 1.0; a[2] = 1.0
    h.step(a)
for i in range(200):
    a = np.zeros(15, dtype=np.float32); a[2] = 1.0
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT）
cd verilator_harness && ./build.sh      # 构建（公开占位参数）
python3 run_verilator.py                # 自测驱动 DUT

# 3) 周期级对拍（local_sim vs 真实 RTL，30000 拍 0 失配）
cd .. && python3 cross_check.py

# 4) 全 bin 可达验证（注入隐藏真值）
python3 verify_all_bins.py              # 目标 ALL 111 BINS REACHABLE
python3 verify_all_bins.py --placeholder   # 占位对照：16 个惰性 bin
```

## 5. 考核重点

1. **协议理解**：以太网帧结构（前导/SFD/填充/FCS/IFG）、经典核心的 7 态
   TX 状态机（含结构性不可达的 WAIT_END）与 3 态 RX 状态机、FCS 校验的
   ~crc_next 判据与流末拍字节重复怪癖、IFG 8 位回绕计数。
2. **异步 FIFO 时序**：`axis_async_frame_fifo` 帧原子交付——帧在 tlast 拍
   整体提交、指针经 2 级同步后才对 MAC 核心可见（约 4~5 拍延迟）；TX 帧
   数据可在上一帧完成前被完整缓存，hold 窗口不能撤回已缓存帧的启动。
3. **黑盒探测**：以 `cov_frame_ok_valid`/`cov_frame_ok_class` 反馈逐帧长
   探测隐藏的"正确子集" `LEN_OK_SET` 与驻留窗口 `FRAME_HOLD_N`。
4. **边界构造**：帧长 0/1/3/60/254/255/256 档位、字节 0/1/0xFE/0xFF、IFG
   0/1/12/255、异步 FIFO 水位 0/1/8/16、错误帧（er 于数据拍 / FCS 拍）、
   坏 FCS 帧、背压恢复、全双工并发。
5. **时序序列**：12 条多拍 SVA 序列与 3 条跨周期 deep 覆盖点要求
   **精确相位编排**（例如在上一帧 PAD 期间预注入下一帧字节实现背靠背、
   用长 RX 数据窗使 RX PAYLOAD 覆盖 TX PREAMBLE/PAYLOAD 拍实现并发）。
