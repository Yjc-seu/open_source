# 赛题：APB 高级定时器控制器 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **APB 高级定时器控制器**（`apbadvtimer_public`，基于开源
pulp-platform/apb_adv_timer 的 APB 寄存器文件与 4 通道定时器数据通路，
Solderpad Hardware License v0.51 许可），支持 16 位加减计数（sawtooth/三角
波）、8 种输入事件模式、8 位预分频、4 个比较通道（7 种比较操作）与事件/
中断输出。你的任务是**设计并生成测试激励（stimulus）**，使被测设计（DUT）
的**功能覆盖率**最大化。

DUT 在标准定时器之上带有若干需要**主动探测**的深水区特性：隐藏的"正确
比较值"子集 `CMP_OK_SET`（只有用这些比较值触发匹配/捕获事件才会进入 hold
窗口并上报 `done_ok`，类别映射完全黑盒）、正确完成后的隐藏驻留窗口
`DONE_HOLD_N`（hold 期间配置写被拒绝、计数暂停），以及捕获链、周期回绕、
事件中断、连续匹配、多模式切换等时序特性。功能的完整定义见
`dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（99 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [d0, d1, cfg_wr, cfg_addr, cfg_d0, cfg_d1, cfg_d2, cfg_d3,
  event_in, pad0..pad5]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 99 个 bin 中 85 个在公开占位参数下可达；14 个依赖隐藏参数（评测端注入
  真值后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
python3 harness.py                            # 随机基线曲线（local 后端）

# 2) 全部 bin 可达性实测（注入评测真值）
python3 verify_all_bins.py                    # ALL 99 BINS REACHABLE
python3 verify_all_bins.py --placeholder      # 占位惰性 14 bin 对照

# 3) 与真实 RTL 周期一致性（WSL，需 Verilator 4.038）
python3 cross_check.py 30000                  # CROSS CHECK PASS（0 失配）

# 4) Verilator 后端评测循环（真实 RTL 数据）
python3 -c "from harness import run_episode; \
            from inference_interface import InferenceInterface; \
            print(run_episode(InferenceInterface(policy='greedy'), \
                  max_steps=3000, backend='verilator')[-1])"
```

## 5. 考察点与难度设计

| 层次 | 考察点 |
|------|--------|
| 基础 | 寄存器映射（含 62/63 重映射）、CH_EN 时钟使能、start/stop 脉冲、计数/比较/模式档位 |
| 边界 | 比较值低 8 位 0/1/254/255、计数值 254/255/65534/65535、周期上界 |
| 条件 | hold 屏蔽、cfg 接受/拒绝、捕获武装、连续匹配 |
| 时序 | 12 条强多拍序列（完整生命周期、捕获链、周期重启、多模式…） |
| 隐藏 | CMP_OK_SET 逐值探测（done_ok class 0..3）、DONE_HOLD_N 窗口长度、class 切换 |

随机基线（`inference_interface` random）约 45%（占位参数），结构化求解可逼近
85/99（占位）/ 99/99（真值）；隐藏机制 + 强多拍序列对纯随机/贪心形成压制。
