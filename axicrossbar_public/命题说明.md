# 赛题：AXI-4 交叉开关 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **AXI-4 交叉开关**（`axicrossbar_public`，基于开源
alexforencich/verilog-axi 的 `axi_crossbar`，MIT 许可），2 主（s0/s1）
2 从（M0: `0x0000..0x0FFF`、M1: `0x1000..0x1FFF`，其余地址 DECERR），
全通道寄存器化（S 侧 simple buffer、M 侧 W 为 skid buffer、M 侧 B/R 直通）。
你的任务是**设计并生成测试激励（stimulus）**，使被测设计（DUT）的
**功能覆盖率**最大化。

DUT 在标准 AXI 交叉开关之上带有若干需要**主动探测**的深水区特性：
隐藏的"正确地址集合"（ADDR_OK_SET，写突发完成时按 AW 地址低 8 位判定；
公开占位全 0、值 0 永不匹配 → 机制完全惰性）、正确完成后隐藏的
hold 驻留窗口（DONE_HOLD_N 拍，结束拍给出 done_ok 类脉冲）、以及
双主冲突仲裁、W 背压恢复、连续多突发、跨从口路由等时序特性。功能的完整
定义见 `dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（104 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [addr_d0, addr_d1, ch_sel, aw_ar, valid_pulse, last,
  wd_d0, wd_d1, ready_ctrl, cfg_wr, cfg_sel, cfg_d0, cfg_d1, pad0, pad1]`
  （见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 104 个 bin 中 90 个在公开占位参数下可达；14 个依赖隐藏参数（评测端注入
  真值后可达，`verify_all_bins.py` 已实测）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
python3 harness.py                      # random 曲线（backend=local）
python3 verify_all_bins.py              # 注入真值：ALL 104 BINS REACHABLE
python3 verify_all_bins.py --placeholder  # 占位对照：14 个惰性 bin

# 2) 周期级对拍（WSL + Verilator，包根目录）
python3 cross_check.py                  # 30000 拍 0 失配 -> CROSS CHECK PASS

# 3) 评测后端冒烟（harness 双后端）
python3 - <<'EOF'
from harness import XbarHarness
import numpy as np
for backend in ("local", "verilator"):
    h = XbarHarness(backend=backend)
    s = h.reset()
    rng = np.random.RandomState(3)
    for _ in range(500):
        s, r, d, i = h.step(rng.uniform(0, 256, 15).astype(np.float32))
    print(backend, "coverage=%.1f%%" % (h.coverage * 100))
EOF
```

## 5. 关键探测点提示（对应 104 bins）

| 类别 | 数量 | 探测要点 |
|---|---|---|
| basic（状态/源/目标/方向/长度/拍数/胜者） | 25 | AW/W/B/AR/R 全事务覆盖；len 档位 0/1/2/4/8 由 cfg 写 awlen/arlen 控制 |
| boundary（地址高/低字节、wdata 边界） | 13 | 地址高低字节 0x00/0x0F/0x10/0x1F/0xFF（未映射）各发一次；wdata 0/1/0xFE/0xFF |
| condition（冲突/忙/valid/ready/hold/cfg） | 13 | 双主同目标 AW-AW / AR-AR；全局 ready_ctrl=0 背压；空闲拍 cfg |
| temporal（done_ok class） | 4 | 隐藏真值：写 AW 低 8 位 ∈ {0x11,0x22,0x33,0x44} 并完成 B → hold → done_ok（占位下惰性） |
| cross | 25 | 组合上表信号（含 hold 相关 3 bin，占位下惰性） |
| seq_hit（Q1..Q12） | 12 | 完整写/读生命周期、双主冲突→仲裁解决、W 背压 ≥2 拍后恢复、hold 持久化、连续多写突发（B 完成 ≤2 拍内新 AW ×3）、busy ≥8、空闲 ≥4、len=0 快速完成（未映射写）、跨从口连续路由、winner 与目标一致 |
| deep | 3 | hold 窗口达到 DONE_HOLD_N-1（真值）、done_ok class 切换（真值）、≥3 种 (src,dst) 路由 |
| sva | 9 | busy 连续 ≥2/4/8、grant 连续 ≥2/4、hold ≥4/DONE_HOLD_N-1（真值）、空闲 ≥4/16 |

细节与拍级时序见 `dut/dut_spec.md`；全部 104 bin 的确定性构造序列见
`verify_all_bins.py`（688 拍内全部命中）。
