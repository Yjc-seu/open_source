# 赛题：APB 寄存器编程式 GPIO 控制器 — 激励生成任务（中高档）

## 1. 赛题背景

给定一个 **APB 寄存器编程式 GPIO 控制器**（`apbgpio_public`，基于开源
pulp-platform/apb_gpio 核心，Solderpad v0.51 许可），支持 32 个双向引脚、
方向/输出/输入（2 级同步）寄存器编程、按位输出置位/清除、每引脚 4 位焊盘
配置（PADCFG）以及边沿可配置的中断（置位锁存、读清除）。你的任务是**设计并
生成测试激励（stimulus）**，使被测设计（DUT）的**功能覆盖率**最大化。

DUT 在标准 GPIO 之上带有若干需要**主动探测**的深水区特性：隐藏的"正确
GPIO_OUT 低字节值子集"（只有写这些值才会上报 `done_ok`，完全黑盒）、正确写
完成后的隐藏驻留窗口（长度隐藏）、以及 hold 屏蔽、中断置位/清除、外部回环
读回等时序特性。功能的完整定义见 `dut/dut_spec.md`（规格书）与
`dut/coverage_meta.json` / `dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（94 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [cfg_wr, cfg_addr, cfg_d0, cfg_d1, cfg_d2, cfg_d3,
  ext_d0, ext_d1, ext_d2, ext_d3, pad0..pad4]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 94 个 bin 中 76 个在公开占位参数下可达；18 个依赖隐藏参数（评测端注入真值
  后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "apbgpio_public")
import numpy as np
from harness import ApbgpioHarness

h = ApbgpioHarness(backend="local")     # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [cfg_wr, cfg_addr, cfg_d0..cfg_d3, ext_d0..ext_d3, pad0..pad4]
def cfg(addr, data, ext=0):
    a = [0.0]*15
    a[0]=1.0; a[1]=float(addr)
    a[2]=data & 0xFF; a[3]=(data>>8)&0xFF; a[4]=(data>>16)&0xFF; a[5]=(data>>24)&0xFF
    a[6]=ext & 0xFF; a[7]=(ext>>8)&0xFF; a[8]=(ext>>16)&0xFF; a[9]=(ext>>24)&0xFF
    return np.asarray(a, dtype=np.float32)
def idle(n, ext=0):
    a = [0.0]*15
    a[6]=ext & 0xFF; a[7]=(ext>>8)&0xFF; a[8]=(ext>>16)&0xFF; a[9]=(ext>>24)&0xFF
    return np.asarray(a, dtype=np.float32)

# 使能输入组、方向全出、写 OUT=0x5A 并外部回送同值
for a in [cfg(0x01,0xFF), cfg(0x00,0xFFFFFFFF), cfg(0x03,0x5A,0x5A)] + [idle(0,0x5A)]*6:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd apbgpio_public/verilator_harness && ./build.sh   # 构建（公开占位参数）
python3 run_verilator.py                            # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd apbgpio_public && python3 cross_check.py
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确 GPIO_OUT 低字节值子集、驻留窗口参数），值不随
  包公布，需通过观测总线或行为反馈探测。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等类别；
  后者要求构造完整的时序序列而非单拍凑值。
- 上游 PADIN 观测需先写 GPIOEN 使能输入组；INTSTATUS 清除走"读清除"（cfg 访问
  地址 0x09）；中断置位需 INTTYPE 与 INTEN 配合外部引脚边沿。
- 建议覆盖：dir/out/in 边界 × padcfg 档位 × 中断置位/清除 × 外部回环读回 ×
  连续写/连续读 × 空闲驻留时序 ×（注入真值后）hold 窗口与 done_ok 类别。
