# 赛题：RV32I 处理器核 — 激励生成任务（最高难档）

## 1. 赛题背景

给定一个 **RV32I 处理器核**（`picorv32_public`，基于开源 YosysHQ/picorv32，
ISC 许可，仓库已 archived 但代码稳定），支持 RV32I 完整整数指令集、内置
指令/数据 RAM（程序与数据初值经 cfg 动作逐字节装载）、单拍内存（mem_ready
恒 1，时序确定）。你的任务是**设计并生成测试激励（stimulus）**，使被测
设计（DUT）的**功能覆盖率**最大化。

DUT 在标准 RV32I 之上带有若干需要**主动探测**的深水区特性：隐藏的"正确
结束指令 opcode 子集"（只有以这些 opcode 的指令触发 trap 结束程序才会进入
hold 并上报 `done_ok`，完全黑盒）、隐藏的驻留窗口长度（TRAP_HOLD_N，期间
屏蔽 run/cfg 并复位挂起 CPU）、以及装载协议、分支方向、load→ALU→store
数据流、trap 后重启等时序特性。功能的完整定义见 `dut/dut_spec.md`
（规格书）与 `dut/coverage_meta.json` / `dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（128 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [cfg_wr, cfg_sel, cfg_data, run, pad0..pad10]`（见规格书 §4）。
  典型流程：cfg_sel=0/1 设装载地址 → cfg_sel=2 逐字节写指令/数据 → run=1
  释放执行 → 等待 trap（cov_trap 脉冲）→ run=0 复位装载下一程序。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 128 个 bin 中 111 个在公开占位参数下可达；17 个依赖隐藏参数（评测端注入
  真值后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "picorv32_public")
import numpy as np
from harness import Picorv32Harness

h = Picorv32Harness(backend="local")   # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [cfg_wr, cfg_sel, cfg_data, run, pad0..pad10]
def cfg(sel, data):
    a = [0.0]*15; a[0]=1.0; a[1]=sel; a[2]=data
    return np.asarray(a, dtype=np.float32)
def run(v):
    a = [0.0]*15; a[3]=v
    return np.asarray(a, dtype=np.float32)

EBREAK = 0x00100073
for a in [cfg(0,0), cfg(1,0)] + [cfg(2,(EBREAK>>(8*b))&0xFF) for b in range(4)]:
    h.step(a)
for a in [run(1)]*30:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd picorv32_public/verilator_harness && ./build.sh   # 构建（公开占位参数）
python3 run_verilator.py                             # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd picorv32_public && python3 cross_check.py
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确结束 opcode 子集、驻留窗口长度），值不随包
  公布，需通过观测总线或行为反馈探测。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等
  类别；后者要求构造完整的程序生命周期（装载→运行→执行链→trap）而非
  单拍凑值。
- 上游 trap 后 CPU 永久停机（trap 电平保持）；只有命中隐藏子集的结束
  opcode 才会进入 hold 并自动重启（pc=0），非匹配 trap 需 run 复位重启。
- 上游 mem 总线地址恒为字对齐（字节通道由 mem_wstrb 指明）；FENCE 按
  上游 default-ALU 路径执行，建议 rd=x0。
- 建议覆盖：opcode/funct3/寄存器边界 × load/store × 分支双向 × 调用-返回
  × 循环迭代 × 数据流序列 ×（注入真值后）hold 窗口与 done_ok 类别。
