# 赛题：ChaCha20 流密码处理核 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **ChaCha20 流密码处理核**（`chacha_public`，基于开源 secworks/chacha
核心，BSD-2-Clause 许可），支持 256 位密钥（32 字节）、64 位 iv（8 字节）、
512 位数据块（64 字节）逐字节配置，init 装载并启动第 0 号块、next 启动后续
块（内部块计数器自动递增）。你的任务是**设计并生成测试激励（stimulus）**，
使被测设计（DUT）的**功能覆盖率**最大化。

DUT 在标准 ChaCha20 之上带有若干需要**主动探测**的深水区特性：隐藏的"正确
块号子集"（只有这些块号完成时才会上报 `done_ok`，完全黑盒；块号从 1 起）、
正确完成后的隐藏驻留窗口（长度隐藏）、完成沿后逐字节流出的真实密钥流
（`cov_data_byte`，须构造真正的块处理生命周期才能观测）、以及完整生命周期/
连续多块/64 字完整写入/多块序列等强时序特性。功能的完整定义见
`dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` / `dut/covergroup.svh`
（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（101 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [d0, d1, cfg_wr, cfg_sel, cfg_d0, cfg_d1, init_pulse, next_pulse,
  pad0..pad5]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 101 个 bin 中 83 个在公开占位参数下可达；18 个依赖隐藏参数（评测端注入
  真值后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "chacha_public")
import numpy as np
from harness import ChachaHarness

h = ChachaHarness(backend="local")     # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [d0, d1, cfg_wr, cfg_sel, cfg_d0, cfg_d1,
#             init_pulse, next_pulse, pad0..pad5]
def key_byte(idx, v):
    a = [0.0]*15; a[0]=1.0; a[1]=idx; a[4]=v
    return np.asarray(a, dtype=np.float32)
def init_p():
    a = [0.0]*15; a[6]=1.0
    return np.asarray(a, dtype=np.float32)
def next_p():
    a = [0.0]*15; a[7]=1.0
    return np.asarray(a, dtype=np.float32)
def wait(n):
    return np.zeros(15, dtype=np.float32)

acts = [key_byte(i, 0x5A) for i in range(32)] + [init_p()] + [wait(0)]*32
for a in acts:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd chacha_public/verilator_harness && ./build.sh   # 构建（公开占位参数）
python3 run_verilator.py                         # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd chacha_public && python3 cross_check.py

# 4) 覆盖可达性验证
python3 verify_all_bins.py               # 真值 101/101
python3 verify_all_bins.py --placeholder # 占位对照（18 惰性 bin）
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确块号子集、驻留窗口长度），值不随包公布，
  需通过观测总线或行为反馈探测。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等类别；
  后者要求构造完整的时序序列而非单拍凑值。
- 实测时序：init 装载 29 拍（KEYLOAD 4 + IVLOAD 2 + BLOCKLOAD 1 + 轮转
  22）、next 块处理 24 拍（core 忙碌 22 拍）；块完成沿后 `cov_data_byte`
  以每拍 1 字节流出 64 拍本块输出（真实密钥流）。
- 命中块完成后触发 hold（16 拍屏蔽 init/next/cfg）+ done_ok；未命中块与
  hold 释放后可直接连发 next，是构造连续多块/背靠背序列的通道。
- 建议覆盖：装载/轮转全状态 × 轮次边界 × 字节边界 × 完整生命周期 ×
  连续多块链 × 64 字完整写入 × 块计数边界 ×（注入真值后）hold 窗口与
  done_ok 类别。
