# 赛题：APB 总线 UART 串行控制器 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **APB 总线接口的 UART 16750 兼容串行控制器**（`apbuart_public`，基于
开源 pulp-platform/apb_uart v0.2.1，Solderpad SHL-0.51 许可），支持 APB 寄存器
编程（16 位分频、5/6/7/8 位字长、无/奇/偶/粘着校验、TX/RX FIFO、内部回环、自动
流控）。你的任务是**设计并生成测试激励（stimulus）**，使被测设计（DUT）的
**功能覆盖率**最大化。

DUT 在标准 16750 之上带有若干需要**主动探测**的深水区特性：隐藏的"正确分频
子集"（只有用这些分频完成字节才会上报 `done_ok`，完全黑盒）、正确完成后的隐藏
驻留窗口（长度隐藏）、以及 APB 写队列/FIFO 门控/回环往返等时序特性。功能的完整
定义见 `dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（106 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [d0, d1, cfg_wr, cfg_addr, cfg_wdata, rx_pin, tx_en, pad0..pad7]`
  （见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 106 个 bin 中 90 个在公开占位参数下可达；16 个依赖隐藏参数（评测端注入真值
  后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "apbuart_public")
import numpy as np
from harness import ApbuartHarness

h = ApbuartHarness(backend="local")     # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [d0, d1, cfg_wr, cfg_addr, cfg_wdata, rx_pin, tx_en, pad0..pad7]
def cfg(addr, data):
    a = [0.0]*15; a[2]=1.0; a[3]=addr; a[4]=data; a[5]=1.0; a[6]=1.0
    return np.asarray(a, dtype=np.float32)
def send(byte):
    a = [0.0]*15; a[0]=byte; a[1]=1.0; a[5]=1.0; a[6]=1.0
    return np.asarray(a, dtype=np.float32)
def wait(n):
    a = [0.0]*15; a[5]=1.0; a[6]=1.0
    return np.asarray(a, dtype=np.float32)

# 16750 配置流程：LCR.DLAB=1 -> DLL=2 -> DLM=0 -> LCR(8bit) -> MCR(LOOP)
for a in [cfg(3,0x80), wait(2), cfg(0,2), wait(2), cfg(1,0), wait(2),
          cfg(3,0x03), wait(2), cfg(4,0x10), wait(2), send(0x5A)] + [wait(0)]*700:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd apbuart_public/verilator_harness && ./build.sh   # 构建（公开占位参数）
python3 run_verilator.py                            # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd apbuart_public && python3 cross_check.py

# 4) 全 bin 可达性验证（注入真值 [1,8,254,255]/16：106/106）
python3 verify_all_bins.py
python3 verify_all_bins.py --placeholder
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确分频子集、驻留窗口长度），值不随包公布，需通过
  观测总线或行为反馈探测。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等类别；
  后者要求构造完整的时序序列而非单拍凑值。
- 上游行为要点：写分频走 LCR.DLAB 流程；APB 写每 3 拍最多 1 次（队列深度 2）；
  **DIV=1 时 RX 失效**（接收场景用 DIV≥2）；回环+AFE 需 MCR.RTS=1；DIV=0 实际
  分频周期 65536。
- 建议覆盖：分频/字节/校验边界 × 回环/外部 × 背靠背与快速收尾 × FIFO 满恢复 ×
  外部错误帧（parity/停止位）× 双向并发 ×（注入真值后）hold 窗口与 done_ok
  类别（Q12 需 div=1 的短帧）。
