# 赛题：APB 事件/中断节点 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个**寄存器编程式事件/中断节点**（`apbnode_public`，基于开源
pulp-platform/apb_node 的 APB 地址解码核心，Solderpad Hardware License
v0.51），支持 32 位事件输入锁存、事件掩码/中断、4 深事件 FIFO、事件计数、
以及可配置地址区间的 APB 解码路由（零等待事件单元 + 慢响应目标 + no-match
路径）。你的任务是**设计并生成测试激励（stimulus）**，使被测设计（DUT）的
**功能覆盖率**最大化。

DUT 在标准事件节点之上带有若干需要**主动探测**的深水区特性：隐藏的"正确
待处理位图子集"（事件锁存后只有 pending 低 8 位属于该集合才会上报
`done_ok`，完全黑盒）、正确锁存后的隐藏驻留窗口（长度隐藏，期间屏蔽配置与
事件）、以及事件风暴/多事件/FIFO 溢出/慢目标等待等时序特性。功能的完整定义
见 `dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（118 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [d0(cfg_rw), d1, cfg_wr, cfg_addr, cfg_d0..cfg_d3, evt_d0..evt_d3,
  pad0..pad2]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 118 个 bin 中 102 个在公开占位参数下可达；16 个依赖隐藏参数（评测端注入
  真值后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "apbnode_public")
import numpy as np
from harness import ApbnodeHarness

h = ApbnodeHarness(backend="local")     # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [cfg_rw, d1, cfg_wr, cfg_addr, cfg_d0..d3, evt_d0..d3, pad0..2]
def cfg(rw, addr, data):
    a = [0.0]*15; a[0]=rw; a[2]=1.0; a[3]=addr
    a[4]=data & 0xFF; a[5]=(data>>8)&0xFF; a[6]=(data>>16)&0xFF; a[7]=(data>>24)&0xFF
    return np.asarray(a, dtype=np.float32)
def evt(v):
    a = [0.0]*15; a[8]=v & 0xFF; a[9]=(v>>8)&0xFF
    a[10]=(v>>16)&0xFF; a[11]=(v>>24)&0xFF
    return np.asarray(a, dtype=np.float32)

for a in [cfg(1,0x00,0xFF)] + [evt(0x1)] + [cfg(0,0x04,0)] + [np.zeros(15,dtype=np.float32)]*8:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd apbnode_public/verilator_harness && ./build.sh   # 构建（公开占位参数）
python3 run_verilator.py                            # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd apbnode_public && python3 cross_check.py

# 4) 全 bin 可达性证明（注入真值 118/118；--placeholder 列出 16 个惰性 bin）
python3 verify_all_bins.py
python3 verify_all_bins.py --placeholder
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确待处理位图子集、驻留窗口长度），值不随包公布，
  需通过观测总线或行为反馈探测。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等类别；
  后者要求构造完整的时序序列而非单拍凑值。
- 掩码只门控 `cov_irq`，不影响事件锁存/入队/计数——探测事件单元时不必先
  写掩码；但 irq 相关交叉需要掩码与 pending 重叠。
- 建议覆盖：掩码/位图边界 × 事件风暴与多事件 × FIFO 满/溢出/排水 × 慢目标
  等待与忙拒绝 × no-match 与直接配置窗 × 读清除生命周期 ×（注入真值后）
  hold 窗口与 done_ok 类别。
