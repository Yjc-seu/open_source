# 赛题：APB 寄存器编程式定时器 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **APB 寄存器编程式 32 位定时器**（`apbtimer_public`，基于开源
pulp-platform/apb_timer 的单 timer 核心，Solderpad Hardware License v0.51），
支持 3 位预分频、计数初值/比较值/使能 CSR 配置、比较匹配与溢出中断、
匹配后自动重载与硬件重触发。你的任务是**设计并生成测试激励（stimulus）**，
使被测设计（DUT）的**功能覆盖率**最大化。

DUT 在标准定时器之上带有若干需要**主动探测**的深水区特性：隐藏的"正确
计数低字节子集"（只有事件发生时 cov_cnt 低 8 位命中集合才会上报
`done_ok`，完全黑盒）、正确事件后的隐藏驻留窗口（长度隐藏）、以及重载
周期/预分频变化/连续事件/多模式等时序特性。功能的完整定义见
`dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（101 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [d0, d1, cfg_wr, cfg_addr, cfg_d0, cfg_d1, cfg_d2, cfg_d3,
  start_pulse, pad0..pad5]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 101 个 bin 中 84 个在公开占位参数下可达；17 个依赖隐藏参数（评测端注入
  真值后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "apbtimer_public")
import numpy as np
from harness import ApbtimerHarness

h = ApbtimerHarness(backend="local")   # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [d0, d1, cfg_wr, cfg_addr, cfg_d0..cfg_d3, start_pulse, pad...]
def cfg(addr, wdata):
    a = [0.0]*15
    a[2]=1.0; a[3]=addr
    a[4]=wdata & 0xFF; a[5]=(wdata>>8) & 0xFF
    a[6]=(wdata>>16) & 0xFF; a[7]=(wdata>>24) & 0xFF
    return np.asarray(a, dtype=np.float32)
def wait(n=1):
    return np.zeros(15, dtype=np.float32)

# cmp=3, init=1, en=1, prescale=0：匹配事件每 ~7 拍周期复现
for a in [cfg(2,3), cfg(0,1), cfg(1,1)] + [wait(0)]*30:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd apbtimer_public/verilator_harness && ./build.sh   # 构建（公开占位参数）
python3 run_verilator.py                             # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd apbtimer_public && python3 cross_check.py

# 4) 全 bin 可达性证明
cd apbtimer_public && python3 verify_all_bins.py
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确计数低字节子集、驻留窗口长度），值不随包公布，
  需通过观测总线或行为反馈探测。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等类别；
  后者要求构造完整的计数/事件时序序列而非单拍凑值。
- 事件天然周期复现（匹配/溢出后计数归零并继续计数），用**小比较值 +
  小预分频**即可高频触发；32 位计数周期极长，溢出用**初值接近
  0xFFFFFFFF + 直通模式**几百拍内复现（无需跑满 2^32 拍）。
- 上游写 REG_CMP 会清零计数；运行中写 REG_TIMER_CTRL 可改预分频/使能——
  可用来构造"运行中改预分频"序列；start_pulse 上升沿可随时重触发计数。
- 建议覆盖：预分频/初值/比较值边界 × 模式矩阵（单次/重载）× 匹配与溢出
  事件 × 生命周期/重载/连续事件/多模式序列 ×（注入真值后）hold 窗口与
  done_ok 类别。
