# 赛题：I2C 总线从机设备 — 激励生成任务（最高难档）

## 1. 赛题背景

给定一个 **I2C 总线从机（slave）设备**（`i2cslave_public`，核心为开源
alexforencich/verilog-i2c 的 `i2c_slave`，MIT 许可），支持 7 位地址匹配、
主机写字节接收、主机读字节发送与缺数据时钟拉伸，完整事务由 START/地址/
数据/STOP 构成。你的任务是**设计并生成测试激励（stimulus）**，使被测设计
（DUT）的**功能覆盖率**最大化。

DUT 在标准 I2C 从机之上带有若干需要**主动探测**的深水区特性：隐藏的
"正确设备地址"子集（完全黑盒，只有以正确地址完整结束事务才会上报
`done_ok`）、正确事务完成后的驻留窗口（长度隐藏），以及把从机读响应字节
的呈现时机纳入激励（`cfg_sel=1` 动作维）带来的位级时序对齐难度（补载时机
直接决定 SCL 时钟拉伸窗口）。功能的完整定义见 `dut/dut_spec.md`（规格书）
与 `dut/coverage_meta.json` / `dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（129 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [cmd_code, cmd_valid, data, sda_in, cfg_wr, cfg_sel, cfg_d0,
  cfg_d1, pad0..pad6]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 全部 bin 在评测真值下均可达（非隐藏项已在占位参数下推演可达）。要求
  尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "i2cslave_public")
import numpy as np
from harness import I2cslaveHarness

h = I2cslaveHarness(backend="local")     # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [cmd_code, cmd_valid, data, sda_in, cfg_wr, cfg_sel,
#            cfg_d0, cfg_d1, pad0..pad6]
def cfg(sel, d0, d1):
    a = [0.0]*15; a[4]=1.0; a[5]=sel; a[6]=d0; a[7]=d1
    return np.asarray(a, dtype=np.float32)
def c(cmd, data=0, sda=1):
    a = [0.0]*15; a[0]=cmd; a[1]=1.0; a[2]=data; a[3]=sda
    return np.asarray(a, dtype=np.float32)

# 命令是 1 深度 pending 队列（新命令覆盖未被接受的旧命令），因此 WRITE 需
# 保持到数据被接受（START 接受后约 97 拍），STOP 需在主机停靠后下发：
for a in [cfg(0, 0x80|0x50, 0), c(1, 0x50), c(2, 0xAB)] + \
         [np.asarray([0]*14+[1], dtype=np.float32)]*200 + [c(4, 0)] + \
         [np.asarray([0]*14+[1], dtype=np.float32)]*100:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd i2cslave_public/verilator_harness && ./build.sh   # 构建（-G 烘焙公开占位参数）
python3 run_verilator.py                             # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd i2cslave_public && python3 cross_check.py
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确地址子集 `ADDR_OK_SET`、驻留窗口拍数
  `DONE_HOLD_N`），值不随包公布，需通过 `cov_done_ok_valid` 观测反馈探测。
- 从机读响应字节由 `cfg_sel=1` 预载/补载：预载（READ 前）无拉伸；补载
  （READ 接受后、拉伸期间）产生 SCL 时钟拉伸（`cov_stretch`），补载时机
  决定拉伸窗口长度——这是区别于寄存器式 DUT 的位级时序难度。
- 写字节延迟一字节时间交付：最后一字节在 STOP 位交付（`cov_tlast=1`），
  中间字节在下一字节第 8 位上升沿交付——单字节写与多字节写的可观测行为
  完全不同。
- 覆盖点除基本/条件/边界/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等类别；
  后者要求构造完整的时序序列而非单拍凑值。
- 建议覆盖：地址匹配/失配/广播 × 读写方向 × 字节边界 × 写多字节连发 ×
  读字节边界（预载与拉伸补载）× NACK 恢复（失配 + 读 NACK 收尾）×
  重复启动地址切换 × 假 ACK（`sda_in=0` 窗口）× 驻留时序 × 正确地址逐槽探测。
