# 赛题：APB 寄存器编程式 SPI 主机控制器 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个**APB 寄存器编程式 SPI 主机控制器**（`apbspi_public`，基于
pulp-platform/apb_spi_master，cmd/addr/dummy/data 四相位流水、TX/RX FIFO、
8 位时钟分频、4 种 CPOL/CPHA 模式、内部回环），你的任务是**设计并生成测试
激励（stimulus）**，使被测设计（DUT）的**功能覆盖率**最大化。

DUT 在标准 SPI 主机之上带有若干需要**主动探测**的深水区特性：一个隐藏的
"正确"时钟分频子集（完全黑盒）、每次正确完成的驻留窗口（长度隐藏）、以及
只有特定分频才会被判定为"正确完成"的类别映射（done_ok class 0..3）。功能的
完整定义见 `dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（114 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [d0, d1, cfg_wr, cfg_addr, cfg_d0, cfg_d1, cmd_pulse, miso,
             pad0..pad6]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 全部 bin 均可达（已在 DUT 上经模拟验证，`verify_all_bins.py` 实测
  114/114）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
python3 - <<'EOF'
import sys; sys.path.insert(0, "apbspi_public")
import numpy as np
from harness import ApbspiHarness

h = ApbspiHarness(backend="local")     # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [d0, d1, cfg_wr, cfg_addr, cfg_d0, cfg_d1, cmd_pulse, miso, pad*]
# 例如：配 SPI_SETUP(clkdiv=2) → SPI_CMD(cmd_len=8) → SPI_STATUS(wr) →
#       SPI_LEN(data_len=8) → cmd_pulse 发送 0x5A。
def cfg(addr, w):
    a = [0.0]*15; a[2]=1.0; a[3]=float(addr)
    a[4]=float(w & 0xFF); a[5]=float((w>>8) & 0xFF)
    return np.asarray(a, dtype=np.float32)
def start(byte):
    a = [0.0]*15; a[0]=float(byte); a[6]=1.0
    return np.asarray(a, dtype=np.float32)

for a in ([0.0]*15, cfg(0x00,0x002), [0.0]*15, [0.0]*15,
          cfg(0x01,0x008), [0.0]*15, [0.0]*15,
          cfg(0x02,0x002), [0.0]*15, [0.0]*15,
          cfg(0x04,0x008), [0.0]*15, [0.0]*15,
          start(0x5A)] + [np.zeros(15,dtype=np.float32)]*80):
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT）
cd apbspi_public/verilator_harness && bash build.sh   # 构建
python3 run_verilator.py                              # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性）
cd apbspi_public && python3 cross_check.py

# 4) 全 bin 可达性
python3 verify_all_bins.py && python3 verify_all_bins.py --placeholder
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确 clk_div 子集、驻留窗口长度），值不随包公布，
  需通过观测总线或行为反馈探测。
- cfg 写序列占 3 拍、cmd_pulse 序列占 5 拍，连续动作会因 APB 占用被拒绝
  （见规格书 §3.4）；hold 窗口内 cfg/cmd 被屏蔽。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing）**等类别；
  后者要求构造完整的时序序列而非单拍凑值。
- 建议覆盖：四种 CPOL/CPHA 模式 × 分频边界（0/1/254/255）× 字节边界 ×
  背靠背多字节 × 回环往返 × miso 变化 × 大帧（data_len=65535）以及
  hold/done_ok 探测（逐 clk_div 扫描）。
