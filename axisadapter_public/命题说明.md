# 赛题：AXI4-Stream 位宽适配器 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **AXI4-Stream 位宽适配器**（`axisadapter_public`，基于开源
alexforencich/verilog-axis 的 `axis_adapter`，MIT 许可）：内部例化两个
适配器实例——pack（16 位字流 → 32 位拍流，2 字打包 1 拍，upsize 分支）
与 unpack（32 位字流 → 16 位拍流，1 字拆包 2 拍，downsize 分支）。两侧
都有真实 AXI4-Stream ready/valid 背压：输出 `m_axis_tready=0` 停流时
输入只能再被 skid 缓冲吸收 1 字，随后 `s_axis_tready=0` 反压。你的任务
是**设计并生成测试激励（stimulus）**，使被测设计（DUT）的**功能覆盖率**
最大化。

DUT 在标准流握手之上带有若干需要**主动探测**的深水区特性：
隐藏的"正确完成字数集合"（WORD_OK_SET，任一适配器一帧适配完成时按帧
字数判定；公开占位全 0、槽值 0 永不匹配 → 机制完全惰性）、正确完成后
隐藏的 hold 驻留窗口（DONE_HOLD_N 拍，结束拍给出 done_ok 类脉冲）、
帧对齐签名（奇数帧末半拍 keep=0011）、输出停流→skid 吸收→输入反压的
级联背压、打包/拆包节拍（2 字/拍 与 1 字/2 拍）等时序特性。功能的完整
定义见 `dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的
  激励序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数
  （127 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [pk_d0, pk_d1, pk_valid, pk_last, pk_mready,
  up_d0, up_d1, up_d2, up_d3, up_valid, up_last, up_mready,
  rsv0, rsv1, rsv2]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速
  迭代；评测阶段以真实 DUT 仿真结果为准。
- 127 个 bin 中 106 个在公开占位参数下可达；21 个依赖隐藏参数（评测端
  注入真值后可达，`verify_all_bins.py` 已实测）。要求尽可能多的 bin 被
  命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
python3 harness.py                      # random 曲线（backend=local）
python3 verify_all_bins.py              # 注入真值：ALL 127 BINS REACHABLE
python3 verify_all_bins.py --placeholder  # 占位对照：21 个惰性 bin

# 2) 周期级对拍（WSL + Verilator，包根目录）
python3 cross_check.py                  # 30000 拍 0 失配 -> CROSS CHECK PASS

# 3) 评测后端冒烟（harness 双后端）
python3 - <<'EOF'
from harness import AxisadapterHarness
import numpy as np
for backend in ("local", "verilator"):
    h = AxisadapterHarness(backend=backend)
    s = h.reset()
    rng = np.random.RandomState(3)
    for _ in range(500):
        s, r, d, i = h.step(rng.uniform(0, 256, 15).astype(np.float32))
    print(backend, "coverage=%.1f%%" % (h.coverage * 100))
EOF
```

## 5. 关键探测点提示（对应 127 bins）

| 层级 | 数量 | 探测要点 |
|---|---|---|
| 基本流握手 | 14 | 复位空闲、单路/双路活动（pack 与 unpack 并发驱动）、ready 0/1、输出拍 valid、拆包低/高半拍 |
| 数据与帧边界 | 37 | 完成帧字数 1/2/254/255（255 为 8 位饱和）；输入字 0/1/0xFFFE/0xFFFF；输出拍 0/1/0xFFFFFFFE/0xFFFFFFFF（unpack 侧 16 位）；pack 末拍 keep=1111（偶数帧满拍）/0011（奇数帧半拍）；字数档位 1/2/4/16/64 |
| 背压与流水状态 | 34 | 输出停流（mready=0）→ skid 吸收 1 字 → 输入反压（bp）；输入挂起∧输出停流的级联；帧内拍序号 1/2/4(/8)；state×ready、bp×state、mstall×state、半拍×state 交叉 |
| 跨周期时序 | 25 | 完整帧生命周期（s tlast hs → m tlast hs）、级联 ≥2 拍、pack 连续握手 ≥4 拍、输入背压 ≥2 拍后恢复、busy ≥8、空闲 ≥4、2 字帧快速完成、长帧 ≥64 字、hold 驻留、done 一致性 |
| 隐藏机制 | 17 | 隐藏真值：帧字数 ∈ {0x05,0x0A,0x0F,0x40} 并完成适配 → hold → done_ok（class=槽位，占位下惰性）；字数×hold、busy×hold 交叉 |

细节与拍级时序见 `dut/dut_spec.md`；全部 127 bin 的确定性构造序列见
`verify_all_bins.py`（2486 拍内全部命中）。
