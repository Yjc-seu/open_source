## 二、DUT 行为概览

上游 `axi_spi_master` 是一个 AXI4 从机寄存器编程式 SPI 主机：STATUS/
CLKDIV/SPICMD/SPIADR/SPILEN/SPIDUM 六寄存器 + 8 深 × 32 位 TX/RX FIFO；
STATUS 写 rd/wr/qrd/qwr 位启动 cmd/addr/dummy/data 四相位传输；支持标准
与四线（quad）模式；TX 数据相位由 FIFO 供数（空则停转背压），RX 数据相位
向 FIFO 收数（满则停转背压）。

自研顶层 `axispimaster_top.v` 内置一个**微型确定性 AXI 主机 FSM**：把
cfg_wr/cmd_pulse/rd_req 原始引脚翻译成对上游寄存器的 2 拍 AXI 写/读序列，
并常驻读 REG_STATUS 嗅探控制器 FSM 状态与 FIFO 水位（纯观测，不改上游
逻辑）；`CLK_OK_SET` / `DONE_HOLD_N` 隐藏参数与 12 条时序序列监视器在
本层实现。

上游怪癖全部原样保留并镜像（本地模型 1:1）：AXI 地址译码 1 位偏移与
0x20..0x3F 写别名（推 FIFO + 写寄存器）、RX FIFO 读的返回数据由
araddr[4:2] 决定、纯 CMD/ADDR 相位传输不发 eot、TX 移位器结束拍预取、
quad 相位期间残留移位器继续计数、quad 短帧永不结束等（见 dut_spec.md
§3.1/§3.6）。

## 三、隐藏机制设计

1. **隐藏"正确"分频子集（机制 A）**：`CLK_OK_SET = {s3,s2,s1,s0}`（4 个
   8 位 clk_div 槽，Verilator -G 编译期烘焙）。一次 SPI 传输完成（eot）
   时若当前 clk_div 命中集合（槽值非 0）→ 进入 hold 窗口 → 1 拍
   `cov_done_ok_valid` 脉冲，`cov_done_ok_class` = 匹配槽位（0..3）。
   公开占位 `CLK_OK_SET=32'h0`（槽值 0 永不匹配）→ done_ok 惰性。
2. **隐藏驻留窗口（机制 B）**：`DONE_HOLD_N`（公开占位 16）为正确传输
   完成后的屏蔽窗口拍数（cov_hold 高 DONE_HOLD_N-1 拍，期间 cfg/cmd/rd
   全部屏蔽）。

依赖隐藏参数的 13 个 bin：done_ok class 0..3（4）、clkdiv×hold（3）、
seq4 hold 保持 + seq5 hold→done_ok（2）、deep hold 窗口 + 类别切换（2）、
hold 驻留 4/full（2）。

## 四、覆盖分层（128 bins）

- **基本功能 34**：spi_mode 3 / clkdiv 档位 4 / 状态 7（IDLE/CMD/ADDR/
  DUMMY/DATA_TX/DATA_RX/WAIT）/ bit_cnt 4 / tx·rx 字节各 4 / TX·RX FIFO
  水位 4+4。
- **数据边界 24**：clkdiv 0/1/254/255、tx/rx 字节 0/1/254/255、
  cmd_len 0/1/31/32、data_len 0/1/8/65535、dummy 0/65535。
- **条件组合 16**：busy、miso、cfg/push/rd 接受、tx/rx 停转、FIFO 满。
- **时序窗口 4 + 交叉 29 + 时序序列 12 + 跨周期 3 + 时序断言 10**。
- 重点覆盖：**命令 FIFO 行为**（水位 0/1/4/8、满、空停转背压与推帧恢复
  seq10、满水位×DATA_TX/IDLE 交叉）、SPI 模式（STD/QUAD_TX/QUAD_RX 链
  seq3）、传输状态（7 状态）、字节边界（TX/RX 0x00/0x01/0xFE/0xFF）。
- 三方一致：`coverage_meta.json` = `covergroup.svh` = `assert_cov.svh`
  + 顶层 cov_seq* 输出（`coverage_simulator.py` 按同一套定义统计）。

## 五、评测接口

- `AxispimasterPublic(clk_ok_set=None, done_hold_n=None)`（黑盒仿真模型，
  周期精确，与 Verilator RTL 经 cross_check 30000 拍 0 失配验证）；
- `CoverageSimulator(meta_path, done_hold_n=16)`；
- `AxispimasterHarness`：DIMS=15，双后端 local/verilator（默认
  verilator），secrets 注入（`eval_secrets_axispimaster.json`）；
- `inference_interface.py`：random + greedy 基线（任务池：配 CLKDIV/
  SPILEN → 推命令帧 → STATUS 启动 → 等待）。

- `python3 verify_all_bins.py --placeholder` → 惰性 bin 与文档 13 个一致
