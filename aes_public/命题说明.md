# 赛题：AES 分组密码处理核 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **AES 分组密码处理核**（`aes_public`，基于开源 secworks/aes 核心，
BSD-2-Clause 许可），支持 AES-128（10 轮）/ AES-256（14 轮）、加密/解密双向、
运行时 keylen 配置与逐字节 key/block 配置。你的任务是**设计并生成测试激励
（stimulus）**，使被测设计（DUT）的**功能覆盖率**最大化。

DUT 在标准 AES 之上带有若干需要**主动探测**的深水区特性：隐藏的"正确 keylen
模式子集"（只有用这些 keylen 完成**加密**才会上报 `done_ok`，完全黑盒）、
正确完成后的隐藏驻留窗口（长度隐藏）、keylen 别名位（2 位 keylen 编码，见
规格书 §1）、以及完整生命周期/连续多块/方向切换/多 keylen 等强时序特性。
功能的完整定义见 `dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（94 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [cmd, arg, cfg_wr, cfg_sel, cfg_d0, cfg_d1, init_pulse, next_pulse,
  encdec, pad0..pad5]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 94 个 bin 中 76 个在公开占位参数下可达；18 个依赖隐藏参数（评测端注入真值
  后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "aes_public")
import numpy as np
from harness import AesHarness

h = AesHarness(backend="local")     # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [cmd, arg, cfg_wr, cfg_sel, cfg_d0, cfg_d1,
#             init_pulse, next_pulse, encdec, pad0..pad5]
def keylen(k):
    a = [0.0]*15; a[0]=3.0; a[4]=k
    return np.asarray(a, dtype=np.float32)
def init_p():
    a = [0.0]*15; a[6]=1.0; a[8]=1.0
    return np.asarray(a, dtype=np.float32)
def next_p():
    a = [0.0]*15; a[7]=1.0; a[8]=1.0
    return np.asarray(a, dtype=np.float32)
def wait(n):
    a = [0.0]*15; a[8]=1.0
    return np.asarray(a, dtype=np.float32)

for a in [keylen(0), init_p()] + [wait(0)]*20 + [next_p()] + [wait(0)]*60:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd aes_public/verilator_harness && ./build.sh   # 构建（公开占位参数）
python3 run_verilator.py                         # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd aes_public && python3 cross_check.py

# 4) 覆盖可达性验证
python3 verify_all_bins.py               # 真值 94/94
python3 verify_all_bins.py --placeholder # 占位对照（18 惰性 bin）
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确 keylen 模式子集、驻留窗口长度），值不随包公布，
  需通过观测总线或行为反馈探测。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等类别；
  后者要求构造完整的时序序列而非单拍凑值。
- 实测时序：密钥扩展 14/18 拍（128/256 位）、块处理 52/72 拍、解密轮次递减、
  加密轮次递增；加密完成可能触发 hold（16 拍屏蔽 init/next/cfg）+ done_ok。
- 解密完成**不**触发 hold，是构造连续多块/背靠背序列的通道。
- 建议覆盖：keylen 档位（含别名位）× 方向 × 字节边界 × 完整生命周期 ×
  连续多块链 × 方向切换 × 多 keylen 切换 × 块计数边界 ×（注入真值后）hold
  窗口与 done_ok 类别。
