# 赛题：定点乘法器运算核 — 激励生成任务（中档）

## 1. 赛题背景

给定一个 **有符号定点乘法运算核**（`mul_public`，基于开源
projf/projf-explore 的 `lib/maths/mul.sv`，MIT 许可，以 WIDTH=32/FBITS=8
的 Q24.8 定点点语义实例化），支持字节级操作数配置、单拍启动与定拍流水线。
你的任务是**设计并生成测试激励（stimulus）**，使被测设计（DUT）的**功能
覆盖率**最大化。

DUT 在标准乘法之上带有需要**主动探测**的深水区特性：隐藏的"正确被乘数
子集"（只有用这些被乘数完成乘法才会上报 `done_ok`，完全黑盒）、正确完成后
的隐藏驻留窗口（长度隐藏）、以及溢出完成/连续乘法/done 后重启/乘 0 乘 1
边界等时序特性。功能的完整定义见 `dut/dut_spec.md`（规格书）与
`dut/coverage_meta.json` / `dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（103 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [d0, d1, cfg_wr, cfg_sel, cfg_d0, cfg_d1, start_pulse, pad0..pad7]`
  （见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 103 个 bin 中 85 个在公开占位参数下可达；18 个依赖隐藏参数（评测端注入
  真值后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "mul_public")
import numpy as np
from harness import MulHarness

h = MulHarness(backend="local")     # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [d0, d1, cfg_wr, cfg_sel, cfg_d0, cfg_d1, start_pulse, pad0..pad7]
def cfg(sel, data):
    a = [0.0]*15; a[2]=1.0; a[3]=sel
    a[4]=data & 0xFF; a[5]=(data>>8) & 0xFF
    return np.asarray(a, dtype=np.float32)
def start():
    a = [0.0]*15; a[6]=1.0
    return np.asarray(a, dtype=np.float32)
def wait(n):
    return np.asarray([0.0]*15, dtype=np.float32)

for a in [cfg(k, (0x100 >> (8*k)) & 0xFF) for k in range(4)] + \
         [cfg(4+k, (0xFFFF >> (8*k)) & 0xFF) for k in range(4)] + \
         [start()] + [wait(0)]*10:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd mul_public/verilator_harness && ./build.sh   # 构建（公开占位参数）
python3 run_verilator.py                        # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd mul_public && python3 cross_check.py

# 4) 全 bin 可达性验证（注入真值后 103/103；--placeholder 对照惰性 bin）
python3 verify_all_bins.py
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确被乘数低 8 位子集、驻留窗口拍数），值不随包公布，
  需通过观测总线或行为反馈探测；**值 0 永不匹配**（规格书 §2.3/§3.3 写清）。
- 上游乘法为**定拍流水线**（迭代拍数与操作数无关，无提前路径）：完整乘法
  start+5 拍回到空闲，"长/短迭代"在本包中映射为满流水线有效完成 / 溢出完成
  两类完成（规格书 §5.1 Q4/Q5）。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等类别；
  后者要求构造完整的时序序列而非单拍凑值。
- 上游 mul 的 `valid` 在 start 时不清零、溢出完成时 `val` 仍更新（规格书
  §3.2），属上游真实行为，可利用其覆盖结果边界 bin。
- 建议覆盖：操作数低/高 8 位边界 × 乘积边界 × 溢出完成 × 完整生命周期与
  idle 驻留时序 × 连续乘法与 done 后重启 ×（注入真值后）hold 窗口与
  done_ok 类别。

## 6. 上游行为要点（黑盒探测参考，规格书 §3.2 已完整列出）

- Q24.8 语义：`prod_t = (a·b)[39:8]`，Gaussian 舍入（round half to even）。
- 溢出判定为符号一致性判定，非严格值域检查；部分值域外乘积以回绕值上报
  valid=1（上游真实语义）。
- 被乘数 b 低 8 位命中隐藏集合 → hold `DONE_HOLD_N` 拍 → 1 拍 done_ok
  （class=匹配槽位，低槽位优先）。
