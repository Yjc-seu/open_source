# 赛题：AXI-4 突发 FIFO — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **AXI-4 突发 FIFO**（`axififo_public`，基于开源
alexforencich/verilog-axi 的 `axi_fifo`，MIT 许可）：写突发经 32 深
W FIFO 入队（`s_axi_wready = !full`）、读响应经 32 深 R FIFO 出队
（`m_axi_rready = !full` 反压上游），AW/AR/B 通道 bypass，顶层以确定性
回环响应器闭合主口。你的任务是**设计并生成测试激励（stimulus）**，使
被测设计（DUT）的**功能覆盖率**最大化。

DUT 在标准 AXI FIFO 之上带有若干需要**主动探测**的深水区特性：
隐藏的"正确写突发长度集合"（LEN_OK_SET，写突发完全入队时按 awlen 低
8 位判定；公开占位全 0、值 0 永不匹配 → 机制完全惰性）、正确完成后
隐藏的 hold 驻留窗口（DONE_HOLD_N 拍，结束拍给出 done_ok 类脉冲）、
以及 W FIFO 满/空背压、排水控制下的填满-读空、连续多突发、
长突发（awlen≥64）、len=0 快速完成等时序特性。功能的完整定义见
`dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的
  激励序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数
  （110 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [addr_d0, addr_d1, ch_sel, aw_ar, valid_pulse, last,
  wd_d0, wd_d1, wstrb_ctrl, aw_ready, ar_ready, cfg_wr, cfg_sel, cfg_d0,
  cfg_d1]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速
  迭代；评测阶段以真实 DUT 仿真结果为准。
- 110 个 bin 中 93 个在公开占位参数下可达；17 个依赖隐藏参数（评测端
  注入真值后可达，`verify_all_bins.py` 已实测）。要求尽可能多的 bin 被
  命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
python3 harness.py                      # random 曲线（backend=local）
python3 verify_all_bins.py              # 注入真值：ALL 110 BINS REACHABLE
python3 verify_all_bins.py --placeholder  # 占位对照：17 个惰性 bin

# 2) 周期级对拍（WSL + Verilator，包根目录）
python3 cross_check.py                  # 30000 拍 0 失配 -> CROSS CHECK PASS

# 3) 评测后端冒烟（harness 双后端）
python3 - <<'EOF'
from harness import AxififoHarness
import numpy as np
for backend in ("local", "verilator"):
    h = AxififoHarness(backend=backend)
    s = h.reset()
    rng = np.random.RandomState(3)
    for _ in range(500):
        s, r, d, i = h.step(rng.uniform(0, 256, 15).astype(np.float32))
    print(backend, "coverage=%.1f%%" % (h.coverage * 100))
EOF
```

## 5. 关键探测点提示（对应 110 bins）

| 类别 | 数量 | 探测要点 |
|---|---|---|
| basic（状态/长度/水位/wstrb/读写） | 24 | AW/W/B/AR/R 全事务覆盖；len 档位 0/1/2/4/8/16/64 由 cfg 写 awlen 控制；水位 16/32 需 `aw_ar=0` 关排水填 FIFO |
| boundary（len 低 8 位/wdata/rdata/addr） | 16 | len 0/1/254/255 各发一次 AW；wdata 0/1/0xFE/0xFF；rdata 边界用 araddr=0x00F、arlen=15（cnt 14/15 → 0x00FE/0x00FF）；addr 0x000/0x001/0xFFE/0xFFF |
| condition（busy/full/empty/bp/cfg） | 10 | 关排水填满 32 深 FIFO；aw_ready=0/ar_ready=0 或满 FIFO 制造挂起反压；空闲拍 cfg 接受 / 忙拍或 cfg_sel≥2 拒绝 |
| temporal（done_ok class） | 4 | 隐藏真值：awlen 低 8 位 ∈ {0x05,0x0A,0x0F,0x40} 并完成入队 → hold → done_ok（占位下惰性） |
| cross | 31 | 组合上表信号（含 hold 相关 6 bin，占位下惰性）；满水位与 WR/RD/WR_RD 状态组合（l32_wr/l32_rd/l32_wrrd） |
| seq_hit（Q1..Q12） | 12 | 完整写/读生命周期、写满后读空、连续多写突发（B 完成 ≤2 拍内新 AW ×3）、hold 持久化、hold→done_ok、W 背压 ≥2 拍后恢复、busy ≥8、空闲 ≥4、len=0 快速完成、长突发（len≥64）、done 一致性 |
| deep | 3 | hold 窗口达到 DONE_HOLD_N-1（真值）、done_ok class 切换（真值）、≥4 种 awlen 多样性 |
| sva | 10 | busy 连续 ≥2/4/8、active 连续 ≥1/8/16、hold ≥4/DONE_HOLD_N-1（真值）、空闲 ≥4/16 |

细节与拍级时序见 `dut/dut_spec.md`；全部 110 bin 的确定性构造序列见
`verify_all_bins.py`（1280 拍内全部命中）。
