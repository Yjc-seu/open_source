# 赛题：AXI-4 RAM 存储从机 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **AXI-4 存储从机**（`axiram_public`，基于开源
alexforencich/verilog-axi 的 `axi_ram`，MIT 许可），64 KiB 存储
（0x0000..0x3FFF，DATA_WIDTH=32/ADDR_WIDTH=16/ID_WIDTH=1），支持突发读/写、
wstrb 字节写、INCR/FIXED 突发、B/R 响应背压；地址范围解码使
`addr≥0x4000` 按 DECERR 应答（bresp/rresp=2'b11，与上游 RAM 恒 OKAY 的
语义实测对照）。你的任务是**设计并生成测试激励（stimulus）**，使被测设计
（DUT）的**功能覆盖率**最大化。

DUT 在标准 AXI-4 RAM 之上带有若干需要**主动探测**的深水区特性：
隐藏的"正确地址集合"（ADDR_OK_SET，写突发完成时按 AW 地址低 8 位判定；
公开占位全 0、值 0 永不匹配 → 机制完全惰性）、正确完成后隐藏的
hold 驻留窗口（DONE_HOLD_N 拍，结束下一拍给出 done_ok 类脉冲）、以及
写后读回一致、连续多突发、W/R 背压恢复、长突发驻留等时序特性。功能的完整
定义见 `dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（107 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [addr_d0, addr_d1, ch_sel, aw_ar, valid_pulse, last,
  wd_d0, wd_d1, wstrb_ctrl, r_ready, b_ready, cfg_wr, cfg_sel, cfg_d0,
  cfg_d1]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 107 个 bin 中 91 个在公开占位参数下可达；16 个依赖隐藏参数（评测端注入
  真值后可达，`verify_all_bins.py` 已实测）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
python3 harness.py                      # random 曲线（backend=local）
python3 verify_all_bins.py              # 注入真值：ALL 107 BINS REACHABLE
python3 verify_all_bins.py --placeholder  # 占位对照：16 个惰性 bin

# 2) 周期级对拍（WSL + Verilator，包根目录）
python3 cross_check.py                  # 30000 拍 0 失配 -> CROSS CHECK PASS

# 3) 评测后端冒烟（harness 双后端）
python3 - <<'EOF'
from harness import AxiramHarness
import numpy as np
for backend in ("local", "verilator"):
    h = AxiramHarness(backend=backend)
    s = h.reset()
    rng = np.random.RandomState(3)
    for _ in range(500):
        s, r, d, i = h.step(rng.uniform(0, 256, 15).astype(np.float32))
    print(backend, "coverage=%.1f%%" % (h.coverage * 100))
EOF
```

## 5. 关键探测点提示（对应 107 bins）

| 类别 | 数量 | 探测要点 |
|---|---|---|
| basic（状态/长度/拍数/方向/突发/strb） | 24 | AW/W/B/AR/R 全事务覆盖；len 档位 0/1/2/4/8 由 cfg 写 awlen/arlen 控制；aw_ar=1 触发 FIXED；wstrb 0/1/3/15 |
| boundary（wdata/rdata/地址高/低字节） | 16 | wdata/rdata 低 16 位 0/1/0xFE/0xFF（低 8 位 0xFE/0xFF 同字，读回须紧跟写）；地址高字节 0x00/0x3F/0x40/0xFF |
| condition（busy/active/valid/resp/背压/hold/cfg） | 16 | addr≥0x4000 写 → DECERR；bvalid/rvalid 期间 b_ready/r_ready=0 背压；空闲拍 cfg |
| temporal（done_ok class） | 4 | 隐藏真值：写 AW 低 8 位 ∈ {0x11,0x22,0x33,0x44} 并完成 B → hold → done_ok（占位下惰性） |
| cross | 22 | 组合上表信号（含 hold 相关 4 bin，占位下惰性） |
| seq_hit（Q1..Q12） | 12 | 完整写/读生命周期、写后读回一致、连续多写突发（B 完成 ≤2 拍内新 AW ×3）、hold 持久化、hold→done_ok、W 背压 ≥2 拍后恢复、busy ≥8、空闲 ≥4、len=0 快速完成、len≥8 长突发、done 一致性 |
| deep | 3 | hold 窗口达到 DONE_HOLD_N（真值）、done_ok class 切换（真值）、≥8 个不同地址相 |
| sva | 10 | busy 连续 ≥2/4/8、active 驻留 ≥1/8/16、hold ≥4/DONE_HOLD_N（真值）、空闲 ≥4/16 |

细节与拍级时序见 `dut/dut_spec.md`；全部 107 bin 的确定性构造序列见
`verify_all_bins.py`（479 拍内全部命中，同一场景在真值烘焙的 Verilator
RTL 上重放同样 107/107）。
