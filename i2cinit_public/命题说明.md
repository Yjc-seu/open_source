# 赛题：I2C 上电初始化控制器 — 激励生成任务（最高难档）

## 1. 赛题背景

给定一个 **I2C 上电初始化控制器**（`i2cinit_public`，核心为开源
alexforencich/verilog-i2c 的 `i2c_init` + `i2c_master`，MIT 许可），收到
一次 start 脉冲即按固定预编程 ROM 自动驱动一整条 I2C 写事务链（单地址段
写 0x50 + 多设备数据块 0x50/0x51/0x52/0x53 + 收尾 STOP），并带一个配置
寄存器文件（prescale 低/高字节 + 备存 ×2，写与读回两条路径）。你的任务是
**设计并生成测试激励（stimulus）**，使被测设计（DUT）的**功能覆盖率**
最大化。

DUT 在标准初始化控制器之上带有若干需要**主动探测**的深水区特性：隐藏的
"正确配置索引"子集（完全黑盒，只有以正确索引完成一次完整 init 事务链才
会上报 `done_ok`）、正确链完成后的驻留窗口（长度隐藏），以及把从机应答/
时钟拉伸电平纳入激励（`sda_in`/`scl_in` 动作维）带来的位级时序对齐难度
（空闲期误拉低 SDA 会制造假 START 卡死链）。功能的完整定义见
`dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` / `dut/covergroup.svh`
（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（126 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [cfg_wr, cfg_idx, cfg_data, cfg_rd, start, sda_in, scl_in,
  pad0..pad7]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 全部 bin 在评测真值下均可达（非隐藏项已在占位参数下推演可达）。要求
  尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "i2cinit_public")
import numpy as np
from harness import I2cinitHarness

h = I2cinitHarness(backend="local")     # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [cfg_wr, cfg_idx, cfg_data, cfg_rd, start, sda_in, scl_in,
#            pad0..pad7]
def cfg(idx, data):
    a = [0.0]*15; a[0]=1.0; a[1]=idx; a[2]=data
    return np.asarray(a, dtype=np.float32)
def lines(start=0, sda=1, scl=1):
    a = [0.0]*15; a[4]=start; a[5]=sda; a[6]=scl
    return np.asarray(a, dtype=np.float32)

for a in [cfg(0,0), cfg(1,0), lines(1,1,1), lines(1,1,1),
          lines(0,1,1)] + [lines(0,1,1)]*2500:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd i2cinit_public/verilator_harness && ./build.sh   # 构建（-G 烘焙公开占位参数）
python3 run_verilator.py                            # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd i2cinit_public && python3 cross_check.py
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确配置索引子集 `CFG_OK_SET`、驻留窗口拍数
  `DONE_HOLD_N`），值不随包公布，需通过 `cov_done_ok_valid` 观测反馈探测。
- 从机应答/时钟拉伸由 `sda_in`/`scl_in` 动作维直接驱动：ACK 需要在主机
  占线位忙的窗口内保持低电平、停止/停靠/空闲期必须释放（否则假 START
  卡死链）；`scl_in=0` 会在主机释放窗内拉伸时钟——这是区别于寄存器式
  DUT 的位级时序难度。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等类别；
  后者要求构造完整的时序序列而非单拍凑值。
- 建议覆盖：配置寄存器编程与读回（边界数据 × 全索引 + 别名） × prescale
  档位 × start 脉冲驱动完整事务链 × NACK 链 × SCL 拉伸 × 链重跑 ×
  prescale 切换 × 链中/hold 中配置写被忽略路径。
