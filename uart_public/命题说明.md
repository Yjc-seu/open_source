# 赛题：UART 串行收发控制器 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **UART 串行收发控制器**（`uart_public`，基于开源
alexforencich/verilog-uart 的 AXI-stream 收发核心，MIT 许可），支持 8 位数据
帧（1 起始位 + 8 数据位 + 1 停止位）、运行时 prescale 配置、内部回环与共享
背压。你的任务是**设计并生成测试激励（stimulus）**，使被测设计（DUT）的
**功能覆盖率**最大化。

DUT 在标准 UART 之上带有若干需要**主动探测**的深水区特性：隐藏的"正确
prescale 子集"（只有用这些 prescale 完成字节才会上报 `baud_ok`，完全黑盒）、
正确完成后的隐藏驻留窗口（长度隐藏）、以及背压/溢出/帧错误/回环往返等时序
特性。功能的完整定义见 `dut/dut_spec.md`（规格书）与
`dut/coverage_meta.json` / `dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（93 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [tx_byte_d0, tx_send, tx_ready, rxd, loopback_en, cfg_wr, cfg_sel,
  cfg_d0, cfg_d1, pad0..pad5]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 93 个 bin 中 77 个在公开占位参数下可达；16 个依赖隐藏参数（评测端注入真值
  后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "uart_public")
import numpy as np
from harness import UartHarness

h = UartHarness(backend="local")     # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [tx_byte_d0, tx_send, tx_ready, rxd, loopback_en,
#             cfg_wr, cfg_sel, cfg_d0, cfg_d1, pad0..pad5]
def cfg(sel, data):
    a = [0.0]*15; a[2]=1.0; a[3]=1.0; a[5]=1.0; a[6]=sel
    a[7]=data & 0xFF; a[8]=(data>>8) & 0xFF
    return np.asarray(a, dtype=np.float32)
def send(byte):
    a = [0.0]*15; a[0]=byte; a[1]=1.0; a[2]=1.0; a[3]=1.0; a[4]=1.0
    return np.asarray(a, dtype=np.float32)
def wait(n):
    a = [0.0]*15; a[2]=1.0; a[3]=1.0; a[4]=1.0
    return np.asarray(a, dtype=np.float32)

for a in [cfg(0,1), cfg(1,0), send(0x5A)] + [wait(0)]*200:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd uart_public/verilator_harness && ./build.sh   # 构建（公开占位参数）
python3 run_verilator.py                         # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd uart_public && python3 cross_check.py
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确 prescale 子集、驻留窗口长度），值不随包公布，
  需通过观测总线或行为反馈探测。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等类别；
  后者要求构造完整的时序序列而非单拍凑值。
- 上游复位后 txd=0，回环模式下 RX 先采样到"全 0 垃圾帧"并产生 frame_error——
  属上游真实行为，可利用其覆盖错误 bin，也可主动规避。
- 建议覆盖：prescale 边界 × 字节边界 × 回环/外部 × 背压恢复 × 连续多字节 ×
  无错误接收 × 快速收尾与空闲驻留时序 ×（注入真值后）hold 窗口与 baud_ok 类别。
