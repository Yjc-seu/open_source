# 赛题：AXI-4 数据宽度适配器 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **AXI-4 数据宽度适配器**（`axiadapter_public`，基于开源
alexforencich/verilog-axi 的 `axi_adapter`，MIT 许可），S 口 16 位数据、
M 口 32 位数据（跨宽 2:1），地址 16 位、ID 1 位。写方向把 2 个 16 位拍
**合并**成 1 个 32 位拍，读方向把 1 个 32 位拍**拆分**成 2 个 16 位拍，
支持字对齐（地址 bit1）字节通道搬移、INCR/FIXED 突发、滑窗（skid）缓冲、
以及由 awcache[1]（配置位 conv_en）选择的窄突发透传 / 全宽窄突发转换
双路径。M 侧接确定性存储器响应器（64 KiB、字节使能写、组合读）并带
节流背压（m_rdy_div，每 d+1 拍 ready 1 拍）。你的任务是**设计并生成测试
激励（stimulus）**，使被测设计（DUT）的**功能覆盖率**最大化。

DUT 在标准宽度适配器之上带有若干需要**主动探测**的深水区特性：隐藏的
"正确地址集合"（ADDR_OK_SET，写突发完成时按 AW 地址低 8 位判定；公开
占位全 0、值 0 永不匹配 → 机制完全惰性）、正确完成后隐藏的 hold 驻留
窗口（DONE_HOLD_N 拍，结束拍给出 done_ok 类脉冲）、跨宽拆分/合并的
字对齐时序、滑窗缓冲排空、M 侧节流反压 S 侧 W 停滞等。功能的完整定义见
`dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（128 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [addr_d0, addr_d1, ch_sel, aw_ar, valid_pulse, last,
  wd_d0, wd_d1, ready_ctrl, cfg_wr, cfg_sel, cfg_d0, cfg_d1, pad0, pad1]`
  （见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 128 个 bin 中 112 个在公开占位参数下可达；16 个依赖隐藏参数（评测端注入
  真值后可达，`verify_all_bins.py` 已实测）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
python3 harness.py                      # random 曲线（backend=local）
python3 verify_all_bins.py              # 注入真值：ALL 128 BINS REACHABLE
python3 verify_all_bins.py --placeholder  # 占位对照：16 个惰性 bin

# 2) 周期级对拍 + 真值 RTL 重放（WSL + Verilator，包根目录）
python3 cross_check.py                  # 30000 拍 0 失配 -> CROSS CHECK PASS
python3 verify_all_bins.py --backend verilator   # 真值烘焙 RTL 重放 128/128

# 3) 评测后端冒烟（harness 双后端）
python3 - <<'EOF'
from harness import AxiadapterHarness
import numpy as np
for backend in ("local", "verilator"):
    h = AxiadapterHarness(backend=backend)
    s = h.reset()
    rng = np.random.RandomState(3)
    for _ in range(500):
        s, r, d, i = h.step(rng.uniform(0, 256, 15).astype(np.float32))
    print(backend, "coverage=%.1f%%" % (h.coverage * 100))
EOF
```

## 5. 关键探测点提示（对应 128 bins）

| 类别 | 数量 | 探测要点 |
|---|---|---|
| basic（状态/长度/拍数/方向/突发/对齐/转换/wstrb/合并类型） | 36 | AW/W/B/AR/R 五相全事务覆盖；len 档位 0/1/2/4/8 由 cfg 写 awlen/arlen 控制；al_unaligned 需地址 bit1=1；cv_pass 需 conv_en=0；mg_partial 未对齐首末字、mg_full 对齐全宽合并字 |
| boundary（地址高/低字节、wdata/rdata 边界） | 16 | 地址高低字节 0x00/0x3F/0x40/0xFF 各发一次；wdata 0/1/0xFE/0xFF 各写一次并同值读回（0xFE/0xFF 同字需紧跟读回） |
| condition（忙/在途/valid/bp/s_bp/m_wait/split/hold/cfg） | 20 | 全局 ready_ctrl=0 背压；m_rdy_div>0 节流 → sbp_on/mw_on；conv 读 → sp_on；空闲拍 cfg |
| temporal（done_ok class） | 4 | 隐藏真值：写 AW 低 8 位 ∈ {0x11,0x22,0x33,0x44} 并完成 B → hold → done_ok（占位下惰性） |
| cross | 28 | 组合上表信号（含 hold 相关 4 bin、合并类型×对齐 4 bin，占位下 4 bin 惰性） |
| seq_hit（Q1..Q14） | 14 | 完整写/读生命周期、写读一致性、写合并 2:1、读拆分 1:2、字对齐部分字写、W 背压 ≥3 拍后恢复、busy ≥8、空闲 ≥4、len=0 快速完成（≤6 拍）、长突发 len≥8、hold 持久化、hold→done_ok、done 一致性 |
| deep | 5 | hold 窗口达到 DONE_HOLD_N（真值）、done_ok class 切换（真值）、≥8 种地址相、合并事件 ≥8、拆分事件 ≥8 |
| sva | 10 | busy 连续 ≥2/4/8、active 连续 ≥1/8/16、hold ≥4/DONE_HOLD_N（真值）、空闲 ≥4/16 |

细节与拍级时序见 `dut/dut_spec.md`；全部 128 bin 的确定性构造序列见
`verify_all_bins.py`（620 拍内全部命中，local_sim 与真值烘焙 Verilator
RTL 双后端一致）。
