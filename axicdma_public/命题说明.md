# 赛题：AXI-4 中央 DMA — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **AXI-4 中央 DMA**（`axicdma_public`，基于开源
alexforencich/verilog-axi 的 `axi_cdma`，MIT 许可），完成一次操作 = 把
`len` 字节从读地址搬运到写地址（内部读/写流水自动进行）。控制侧是
**寄存器编程 + 状态轮询**式：通过原始引脚把 CSR（READ_ADDR / WRITE_ADDR /
LEN / CTRL）写进顶层内部寄存器组，顶层 FSM 以描述符流下发 CDMA，并轮询其
状态流；CDMA 数据口接**确定性自动响应从机**（写响应 OKAY 1 拍、读响应返回
地址衍生数据 1 拍，AR 单突发排队）。你的任务是**设计并生成测试激励
（stimulus）**，使被测设计（DUT）的**功能覆盖率**最大化。

DUT 在标准 CDMA 之上带有若干需要**主动探测**的深水区特性：隐藏的"正确长度
低 8 位集合"（LEN_OK_SET，DMA 完成时按长度低 8 位判定；公开占位全 0、槽值
0 永不匹配 → 机制完全惰性）、正确完成后隐藏的 hold 驻留窗口（DONE_HOLD_N
拍，结束拍给出 done_ok 类脉冲）、以及上游 axi_cdma 的原生怪癖（长度单位是
字节、len=0 回绕挂起、地址 4 字节对齐与 4K 拆突发、R→W 数据经 32 深输出
FIFO 流水等）。功能的完整定义见 `dut/dut_spec.md`（规格书）与
`dut/coverage_meta.json` / `dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（117 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [d0, d1, cfg_wr, cfg_sel, cfg_d0, cfg_d1, start_pulse,
  pad0..pad7]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 117 个 bin 中 102 个在公开占位参数下可达；15 个依赖隐藏参数（评测端注入
  真值后可达，`verify_all_bins.py` 已实测）。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
python3 harness.py                      # random 曲线（backend=local）
python3 verify_all_bins.py              # 注入真值：ALL 117 BINS REACHABLE
python3 verify_all_bins.py --placeholder  # 占位对照：15 个惰性 bin

# 2) 周期级对拍（WSL + Verilator，包根目录）
python3 cross_check.py                  # 30000 拍 0 失配 -> CROSS CHECK PASS

# 3) 评测后端冒烟（harness 双后端）
python3 - <<'EOF'
from harness import AxicdmaHarness
import numpy as np
for backend in ("local", "verilator"):
    h = AxicdmaHarness(backend=backend)
    s = h.reset()
    rng = np.random.RandomState(3)
    for _ in range(500):
        s, r, d, i = h.step(rng.uniform(0, 256, 15).astype(np.float32))
    print(backend, "coverage=%.1f%%" % (h.coverage * 100))
EOF
```

## 5. 关键探测点提示（对应 117 bins）

| 类别 | 数量 | 探测要点 |
|---|---|---|
| basic（状态/长度/地址/拍数/方向/状态标志） | 25 | 影子机 6 态全走一遍；len 档位 1/2/4/8/16；地址高/低档位 0/中/255；beats 0/1/4/16/256 由 len 1/4/16/64/1024 触发 |
| boundary（len 低 8 位、地址边界） | 14 | len 低 8 位 0/1/254/255（只编程即可）；读地址 0/1/0xFFFE/0xFFFF |
| condition（busy/done/接受/拒绝/hold/轮询） | 12 | 传输期间 cfg/start 一律拒绝（rej_on）；hold 期间同样拒绝；DMA_WR 期间 poll_on |
| temporal（done_ok class） | 4 | 隐藏真值：完成长度低 8 位 ∈ {1,2,4,8} → hold → done_ok class 0..3（占位下惰性） |
| cross | 37 | state×rd_wr、addr×len（编程组合即命中）、len×hold（len=1 与 257 的 hold 交叉）、done×state、state×len、state×busy、hold×done_ok、rd_wr×busy（DONE 拍 wr_b0） |
| seq_hit（Q1..Q12） | 12 | 完整生命周期 cfg→start→读拍→写拍→done；≥3 次完成；len≥256 长突发；len≤8 快速完成（≤32 拍）；hold ≥4；hold→done_ok；done/done_ok 后 ≤3 拍重启；busy ≥8；IDLE ≥4；读写对；≥3 种长度；done 一致性 |
| deep | 3 | hold 窗口达到 DONE_HOLD_N-1（真值）、done_ok class 切换（真值）、≥4 种长度完成 |
| sva | 10 | busy 连续 ≥2/4/8、active 驻留 ≥1/8/16、hold ≥4/DONE_HOLD_N-1（真值）、空闲 ≥4/16 |

细节与拍级时序见 `dut/dut_spec.md`；全部 117 bin 的确定性构造序列见
`verify_all_bins.py`（793 拍内全部命中）。注意 **len=0 只编程不触发**：0
长度 DMA 按上游语义会永久挂起（busy 恒 1），见规格书 §3.3。
