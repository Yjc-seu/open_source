# 赛题：Project F UART 串行收发控制器 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **UART 串行收发控制器**（`projfuart_public`，基于开源 Project F
Verilog Library 的 8N1 收发核心 uart_tx/uart_rx/uart_baud，MIT 许可），支持
8 位数据帧（1 起始位 + 8 数据位 + 1 停止位）、**运行时分频 div 输入引脚**
（div≥1：每 16× 过采样拍 div 个时钟；div=0：上游 uart_baud 9600 基准回退）、
内部回环、共享背压与帧错误/溢出/奇偶错误监视。你的任务是**设计并生成测试
激励（stimulus）**，使被测设计（DUT）的**功能覆盖率**最大化。

DUT 在标准 UART 之上带有若干需要**主动探测**的深水区特性：隐藏的"正确
分频子集"（只有用这些 div 完成字节才会上报 `done_ok`，完全黑盒；4 个槽位
中槽 0 保留永不匹配）、正确完成后的隐藏驻留窗口（长度隐藏）、以及背压/
溢出/帧错误/奇偶错误/回环往返等时序特性。功能的完整定义见
`dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` /
`dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（104 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [tx_byte_d0, tx_send, tx_ready, rxd, loopback_en, cfg_wr,
  cfg_sel, cfg_d0, cfg_d1, pad0..pad5]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 104 个 bin 中 89 个在公开占位参数下可达；15 个依赖隐藏参数（评测端注入
  真值后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "projfuart_public")
import numpy as np
from harness import ProjfuartHarness

h = ProjfuartHarness(backend="local")     # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [tx_byte_d0, tx_send, tx_ready, rxd, loopback_en,
#             cfg_wr, cfg_sel, cfg_d0, cfg_d1, pad0..pad5]
def cfg(sel, d0):
    a = [0.0]*15; a[2]=1.0; a[3]=1.0; a[5]=1.0; a[6]=sel; a[7]=d0
    return np.asarray(a, dtype=np.float32)
def send(byte):
    a = [0.0]*15; a[0]=byte; a[1]=1.0; a[2]=1.0; a[3]=1.0; a[4]=1.0
    return np.asarray(a, dtype=np.float32)
def wait(n):
    a = [0.0]*15; a[2]=1.0; a[3]=1.0; a[4]=1.0
    return np.asarray(a, dtype=np.float32)

for a in [cfg(0, 8), cfg(1, 0), send(0x5A)] + [wait(0)]*6000:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd projfuart_public/verilator_harness && ./build.sh   # 构建（公开占位参数）
python3 run_verilator.py                              # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd projfuart_public && python3 cross_check.py

# 4) 逐 bin 可达性验证
python3 verify_all_bins.py
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确分频子集、驻留窗口长度），值不随包公布，
  需通过观测总线或行为反馈探测。
- div 为**运行时输入引脚**：帧传输期间改变 div 会实时改变波特节拍，构造
  时序序列时应保持帧内 div 稳定（div=0 为 9600 基准回退，位周期约 10417
  拍；div=255 帧长仅约 161 拍，适合快速扫频）。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等类别；
  后者要求构造完整的时序序列而非单拍凑值。
- 错误注入三通道：frame error（parity_mode=0 时停止位位置为 0）、overrun
  （tx_ready=0 保持至第二帧完成）、parity error（parity_mode=1/2 时第 9 位
  位置与数据奇偶不符）；错误脉冲均落在 RX STOP 状态窗口（fe/pe/ov ×
  rx_state 交叉 bin 由此可达）。
- 建议覆盖：div 全档 × 字节边界 × 回环/外部 × 背压恢复 × 背靠背多字节 ×
  无错误接收 × 双向并发 × 快速收尾与空闲驻留时序 ×（注入真值后）hold 窗口
  与 done_ok 类别 1..3。
