# 赛题：AXI-Stream FWFT 流式 FIFO — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **AXI4-Stream FWFT 流式 FIFO**（`axisfifo_public`，基于开源
alexforencich/verilog-axis 的 `axis_fifo.v`，MIT 许可），支持 32 位 × 32
深的流式缓冲、逐拍 tvalid/tready/tlast 控制、输入/输出双向背压与水位观测。
你的任务是**设计并生成测试激励（stimulus）**，使被测设计（DUT）的
**功能覆盖率**最大化。

DUT 在标准流式 FIFO 之上带有若干需要**主动探测**的深水区特性：隐藏的
"正确帧长子集"（只有用这些帧长在输出端完整出帧才会上报 `done_ok`，完全
黑盒）、正确完成后的隐藏驻留窗口（长度隐藏）、以及灌满/排空/背压恢复/
帧链等时序特性。功能的完整定义见 `dut/dut_spec.md`（规格书）与
`dut/coverage_meta.json` / `dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（103 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [td_d0, td_d1, td_d2, td_d3, tvalid, tlast, tready, pad0..pad7]`
  （见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 103 个 bin 中 82 个在公开占位参数下可达；21 个依赖隐藏参数（评测端注入
  真值后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 harness.py
python3 inference_interface.py

# 2) 与真实 RTL 对拍（WSL/Linux + Verilator）
python3 cross_check.py          # 0 失配证明 local_sim 周期级等价

# 3) bin 可达性实测（评测端注入真值后 100%）
python3 verify_all_bins.py
```

## 5. 规则与提示

- 允许使用任何本地工具与脚本探索 DUT 行为；评分只看最终激励在评测 DUT 上
  的 bin 命中数。
- `dut/` 下的 `axis_fifo.v` 为上游原样文件（仅加来源注释头），`dut_spec.md`
  不泄露任何隐藏参数值；请勿以解析 RTL 内部实现代替黑盒探测。
- 隐藏机制要点（黑盒探测线索见规格书 §1/§3/§5）：
  - 帧在**输出端**完成（tlast 出队）且帧长命中隐藏集合的**非零槽**才进入
    hold 窗口，随后 1 拍 `done_ok`（class=槽位 1..3）；槽 0 永不匹配。
  - hold 期间输入被屏蔽，输出排水不受限；hold 长度隐藏（公开占位 16 拍）。
  - 帧长边界 254/255 可通过长帧流式构造（FIFO 深度只限制同时存储，不限制
    帧长）。
- 难度分档：基本功能/条件组合 easy，数据边界/交叉 medium，时序序列
  hard~hardest，deep（hold 窗口长度、类别切换）hardest。
