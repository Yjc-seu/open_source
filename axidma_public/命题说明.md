# 赛题：AXI-4 流式 DMA — 激励生成任务（最高难档）

## 1. 赛题背景

给定一个 **AXI-4 流式 DMA**（`axidma_public`，基于开源
alexforencich/verilog-axi 的 `axi_dma`，MIT 许可），完成一次操作 = 把 `len`
字节从读地址搬运到写地址：读引擎经 AXI 读总线取数 → AXI-stream 读流回环到
写流 → 写引擎经 AXI 写总线写出。控制侧是**寄存器 + 描述符编程**式：通过原始
引脚把描述符写进顶层内部 **4×48 位描述符 RAM**（{rd_addr, wr_addr, len}，
槽号 = CTRL[3:1]），start 时顶层 FSM 把当前槽描述符以描述符流同时下发
读/写引擎，并轮询写引擎状态流；DMA 数据口接**确定性自动响应从机**（写响应
OKAY 1 拍、读响应返回地址衍生数据 1 拍，AR 单突发排队）。你的任务是**设计并
生成测试激励（stimulus）**，使被测设计（DUT）的**功能覆盖率**最大化。

DUT 在标准流式 DMA 之上带有若干需要**主动探测**的深水区特性：隐藏的"正确
长度低 8 位集合"（LEN_OK_SET，DMA 完成时按长度低 8 位判定；公开占位全 0、
槽值 0 永不匹配 → 机制完全惰性）、正确完成后隐藏的 hold 驻留窗口
（DONE_HOLD_N 拍，结束拍给出 done_ok 类脉冲）、以及上游 axi_dma 的原生怪癖
（长度单位是字节、len=0 回绕挂起、地址 4 字节对齐与 4K 拆突发、写引擎等
首个流拍才宣告 AW、读/写两级 32 深 FIFO 流水等）。功能的完整定义见
`dut/dut_spec.md`（规格书）与 `dut/coverage_meta.json` / `dut/covergroup.svh`
（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（128 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [d0, d1, cfg_wr, cfg_sel, cfg_d0, cfg_d1, start_pulse,
  pad0..pad7]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 128 个 bin 中 113 个在公开占位参数下可达；15 个依赖隐藏参数（评测端注入
  真值后可达，`verify_all_bins.py` 已实测）。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
python3 harness.py                      # random 曲线（backend=local）
python3 verify_all_bins.py              # 注入真值：ALL 128 BINS REACHABLE
python3 verify_all_bins.py --placeholder  # 占位对照：15 个惰性 bin

# 2) 周期级对拍（WSL + Verilator，包根目录）
python3 cross_check.py                  # 30000 拍 0 失配 -> CROSS CHECK PASS

# 3) 评测后端冒烟（harness 双后端）
python3 - <<'EOF'
from harness import AxidmaHarness
import numpy as np
for backend in ("local", "verilator"):
    h = AxidmaHarness(backend=backend)
    s = h.reset()
    rng = np.random.RandomState(3)
    for _ in range(500):
        s, r, d, i = h.step(rng.uniform(0, 256, 15).astype(np.float32))
    print(backend, "coverage=%.1f%%" % (h.coverage * 100))
EOF
```

## 5. 关键探测点提示（对应 128 bins，五层）

| 层 | 类别 | 数量 | 探测要点 |
|---|---|---|---|
| L1 basic | 状态/槽位/长度/地址/拍数/方向/通道节拍 | 38 | 影子机 5 态全走一遍；CTRL[3:1] 切 4 个描述符槽；len 档位 1/2/4/8/16；地址高/低档位 0/中/255；**ch_beat 七相**（AR/R/AW/W/B/R+W 双相）；R/W 拍数 0/4/16/256 由 len 16/64/1024 触发 |
| L2 boundary | len 低 8 位、地址边界、拍数边界 | 15 | len 低 8 位 0/1/254/255（只编程即可）；地址边界 0/1/0xFFFE/0xFFFF；R 拍数 1/15/255、W 拍数 1/255 由 len 4/60/1020 触发 |
| L3 condition | busy/done/接受/拒绝/hold/轮询/描述符 | 14 | 传输期间 cfg/start 一律拒绝（rej_on）；wlast 后 poll_on；描述符下发脉冲 |
| L4 temporal+cross | done_ok class、交叉组合 | 37 | 隐藏真值：完成长度低 8 位 ∈ {1,2,4,8} → hold → done_ok class 0..3（占位下惰性）；state×rd_wr、addr×len（编程组合即命中）、len×hold（len=1 与 257 的 hold 交叉）、done×state、state×len、state×busy、hold×done_ok、rd_wr×busy、slot×desc（slot3 下发） |
| L5 seq+deep+sva | 时序序列、跨周期、驻留 | 24 | Q1..Q12（cfg→start→描述符→读拍→写拍→done 全生命周期、搬运链 ≥3 次、len≥256 长突发、len≤8 快速完成、hold ≥4、hold→done_ok、done/ok 后 ≤3 拍重启、busy ≥8、IDLE ≥4、四相节拍齐备、≥3 种长度、done 一致性）；hold 窗口 DONE_HOLD_N-1、class 切换、≥4 种长度（真值）；busy 2/4/8、active 8/16、hold 4/full（真值）、空闲 4/16 |

细节与拍级时序见 `dut/dut_spec.md`（§3.2 含 len=4 逐拍时序与 1/4/8/16/64/
256/1024 字节的实测完成拍表）；全部 128 bin 的确定性构造序列见
`verify_all_bins.py`（1191 拍内全部命中）。注意 **len=0 只编程不触发**：0
长度 DMA 按上游语义会永久挂起（busy 恒 1），见规格书 §3.3。
