# 赛题：4 单元 APB 定时器组 — 激励生成任务（中高难档）

## 1. 赛题背景

给定一个 **4 单元 APB 寄存器编程式定时器组**（`timerunit_public`，基于开源
pulp-platform/timer_unit 的 apb_timer_unit 单元，Solderpad Hardware License
v0.51），每单元支持 2 路 32 位计数器（lo/hi，可级联为 64 位）、8 位预分频、
参考时钟模式、比较超时中断、单次模式/到达清计数/输入事件模式等特性位，以及
计数预装载、启动、复位寄存器。顶层还提供**喂狗脉冲**：对目标单元 lo/hi 注入
外部事件，该侧 IEM 置位时事件重新使能定时器（喂狗成功，倒计时重来）。你的
任务是**设计并生成测试激励（stimulus）**，使被测设计（DUT）的**功能覆盖率**
最大化。

DUT 在标准定时器组之上带有若干需要**主动探测**的深水区特性：隐藏的"正确
超时值低字节子集"（只有超时事件发生时触发单元比较值低 8 位命中集合才会上报
`done_ok`，完全黑盒）、正确事件后的隐藏驻留窗口（长度隐藏）、喂狗/单次模式/
多单元竞速等时序特性。功能的完整定义见 `dut/dut_spec.md`（规格书）与
`dut/coverage_meta.json` / `dut/covergroup.svh`（覆盖定义）。

## 2. 评测方式

- 评分依据：在**评测 DUT**（与本地 Verilator 模型一致）上运行你生成的激励
  序列后，`coverage_simulator.py` 统计的 **bin 命中数 / 总 bin 数（128 个）**。
- 激励以**动作序列**形式提交：每个时钟周期一个动作，
  `action = [d0, d1, cfg_wr, cfg_addr, cfg_d0, cfg_d1, cfg_d2, cfg_d3,
  start_pulse, pad0..pad5]`（见规格书 §4）。
- 本地开发阶段可通过 `local_sim.py` + `coverage_simulator.py` 快速迭代；
  评测阶段以真实 DUT 仿真结果为准。
- 128 个 bin 中 111 个在公开占位参数下可达；17 个依赖隐藏参数（评测端注入
  真值后可达）。要求尽可能多的 bin 被命中。

## 4. 使用流程

```bash
# 1) 本地快速迭代（Python，无需 Verilator）
#    推荐直接用 harness（与评测一致的动作解码 + 覆盖率）：
python3 - <<'EOF'
import sys; sys.path.insert(0, "timerunit_public")
import numpy as np
from harness import TimerunitHarness

h = TimerunitHarness(backend="local")   # 评测端注入真值时传 secrets
h.reset()
# 动作：15 维 [d0, d1, cfg_wr, cfg_addr, cfg_d0..cfg_d3, start_pulse, pad...]
def cfg(unit, reg, wdata):
    a = [0.0]*15
    a[2]=1.0; a[3]=(unit<<4)|reg
    a[4]=wdata & 0xFF; a[5]=(wdata>>8) & 0xFF
    a[6]=(wdata>>16) & 0xFF; a[7]=(wdata>>24) & 0xFF
    return np.asarray(a, dtype=np.float32)
def wait(n=1):
    return np.zeros(15, dtype=np.float32)

# unit0：cmp=6, CFG=IRQ|EN（0x05）-> 超时事件每 ~7 拍周期复现
for a in [cfg(0,4,6), cfg(0,0,0x05)] + [wait(0)]*30:
    h.step(a)
print("coverage:", h.coverage)
EOF

# 2) Verilator 仿真（真实 DUT，Linux/WSL）
cd timerunit_public/verilator_harness && ./build.sh   # 构建（公开占位参数）
python3 run_verilator.py                             # 驱动 DUT

# 3) 对拍校验（本地模型与 Verilator 周期一致性，注入隐藏真值后运行）
cd timerunit_public && python3 cross_check.py

# 4) 全 bin 可达性证明
cd timerunit_public && python3 verify_all_bins.py
```

## 5. 提示

- 覆盖率报告只返回 **bin 命中向量**（哪些 bin 命中），不暴露内部信号。
- 存在若干**隐藏参数**（正确超时值低字节子集、驻留窗口长度），值不随包公布，
  需通过观测总线或行为反馈探测。
- 覆盖点除基本/边界/条件/交叉外，还包含**时序窗口**、**跨周期（deep）**、
  以及**时序断言（SVA cover property，含 dataflow / timing_param）** 等类别；
  后者要求构造完整的计数/事件时序序列而非单拍凑值。
- 超时事件可用**小比较值**高频触发（CMP_CLR 位使到达后计数自动清零，事件
  周期 = 比较值+1 拍）；64 位模式超时需 lo 到达比较值且 hi 停在 0（lo 未
  溢出前 hi 恒 0，tr_hi=1），小比较值即可复现。注意比较值为 0 且计数为 0 时
  target_reached 恒 1（0==0），写 CMP 后需留 1 拍让寄存比较器反映新值。
- 喂狗（start_pulse）需要目标单元该侧 IEM 置位才生效；喂狗 + TIMER_RESET
  写构成"重启倒计时"组合序列。
- 建议覆盖：interval（比较值）×预分频全档（timer_interval_sweep）× 特性
  矩阵 × 多单元活跃矩阵（单/双/三/四单元同跑）× 生命周期/单次/喂狗/连续
  事件/扫描序列 ×（注入真值后）hold 窗口与 done_ok 类别。
